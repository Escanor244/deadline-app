KAIROS STUDIO // PROJECT DESCRIPTIONS FOR COPY-PASTING
========================================================

--- [ 1. SHORT ELEVATOR PITCH (One-Liner for GitHub / Social) ] ---
A high-precision reverse-engineering deadline planner and retina countdown lock screen generator. 100% client-side with hybrid MongoDB sync and universal AI integration.

-------------------------------------------------------------------
--- [ 2. STANDARD PROJECT DESCRIPTION (For Portfolio / Submissions) ] ---
Kairos is an anti-slop countdown lock screen studio and reverse-planning command center. Instead of generic templates, Kairos mathematically works backward from your high-stakes target date into actionable milestone checkpoints, calculates pacing velocity, and turns your objective into an unmissable, designer-grade countdown lock screen.

Key Features:
- Reverse-Engineering Planner: Calculates backward milestone phases (T-weeks, T-48h, T-2h) with estimated workload hours, task checklists, and celebratory confetti.
- Retina Lock Screen Generator: HTML5 canvas compositor renders native OLED wallpapers (iPhone 16 Pro, Google Pixel 9, Desktop 16:9) with phone safe-zone engineering that keeps your device's native clock unobstructed.
- Live Fullscreen Lock Screen Mode: Turns any phone, tablet, or monitor into a live ticking countdown HUD with synthesized ambient focus audio (Brown noise, Pink noise, 108Hz Binaural drone, Clock tick).
- Calendar Sync & Alarms: 1-click RFC 5545 .ics calendar export with automated 24-hour and 2-hour pre-deadline alarms (Apple Calendar, Google Calendar, Outlook).
- Universal AI Engine: Server-side integration supporting Groq (Llama 3.3), OpenRouter, Google Gemini, or OpenAI with zero client key exposure.
- Universal Hybrid Persistence: Works out-of-the-box on Vercel with zero environment variables (LocalStorage + 1-click JSON backup/restore + ?share= URL encoding) with optional MongoDB Atlas cloud sync.

Tech Stack: Next.js 15 (App Router), TypeScript, Tailwind CSS, Lucide Icons, MongoDB Native Driver, HTML5 Canvas Rasterizer, Web Audio API.
